# Feature Matrix

Public: Home, rooms, facilities, gallery, rules, FAQ, location, contact, admissions.
Resident: profile, documents, room/bed, billing, payments, receipts, announcements, notifications, complaints.
Admin: command center, applications, verification, members, rooms/beds, check-in/out, billing, payments, complaints, announcements, documents, reports, settings, feature flags, audit logs.
Automation: fee reminders, overdue detection, scheduled announcements and complaint escalation.
Integrations: provider abstractions for email, SMS, WhatsApp and Razorpay.
